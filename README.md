# SMOKE-VID-dev

Программный пакет для формирования, валидации и управления наборами данных видеопоследовательностей в формате **Time-COCO**, предназначенный для обучения и оценки моделей пространственно-временного обнаружения дыма (например, SMOKE-DETR).

## Особенности
- Поддержка модифицированного формата **Time-COCO**, обеспечивающего хранение истории предыдущих кадров (`prev_imgs`) при полной обратной совместимости со стандартом COCO.
- Автоматизированная конвертация синтетических данных, сгенерированных в игровом движке Unity.
- Гибкое управление структурой выборок: разделение на категории `POSITIVE` / `NEGATIVE` и `TRAIN` / `VAL`.
- Комплексная валидация целостности структуры, соответствия файлов и семантики аннотаций.

## Требования
- Python 3.8+
- Зависимости: `opencv-python`, `pycocotools`, `numpy`, `scikit-learn`, `tqdm`

Установка зависимостей:
```bash
pip install opencv-python pycocotools numpy scikit-learn tqdm
```

## Структура и назначение скриптов

### 1. Конвертация синтетических данных
**`synth.py`**  
Преобразует промежуточные данные из Unity (последовательности кадров и JSON-аннотации) в структуру Time-COCO с разделением на обучающую и валидационную выборки.
```bash
python synth.py --root_dir /path/to/unity/output --output_dir /path/to/dataset --train_ratio 0.8 --n_prev 5
```

### 2. Управление типом выборки
**`train2val.py`** / **`val2train.py`**  
Изменяют категорию субдиректории: переносят изображения между папками `train2017` и `val2017`, переименовывают соответствующие JSON-файлы аннотаций и удаляют исходную пустую директорию.
```bash
python train2val.py /path/to/dataset_root
python val2train.py /path/to/dataset_root
```

### 3. Очистка аннотаций
**`clear-anns.py`**  
Обнуляет массив `annotations` в JSON-файлах формата COCO. Используется для корректного формирования подвыборок категории `NEGATIVE` (кадры без дыма).
```bash
python clear-anns.py /path/to/negative_train_dir /path/to/negative_val_dir
```

### 4. Валидация и статистика
**`summary.py`**  
Выполняет рекурсивный анализ микро-датасетов. Проверяет целостность структуры, отсутствие расхождений между файловой системой и метаданными, семантическую корректность (отсутствие аннотаций в `NEGATIVE`, наличие в `POSITIVE`) и выводит сводную статистику.
```bash
python summary.py /path/to/dataset_root --detailed
```

### 5. Сборка итогового набора
**`merge.py`**  
Объединяет множество субдиректорий в единый датасет. Позволяет настраивать глобальный шаг выборки кадров и максимальную длину последовательности (`prev_imgs`).
```bash
python merge.py --source /path/to/datasets_root --output /path/to/final_dataset --type train --step 1 --max-prev 32
```

### 6. Визуализация
**`check.py`**  
Генерирует мозаичные изображения для визуального контроля качества разметки. Отображает основной кадр, указанные предыдущие кадры (`prev_imgs`) и отрисовывает ограничивающие рамки только на основном кадре.
```bash
python check.py /path/to/dataset_dir --max-series 50 --max-prev 5
```

## Формат Time-COCO
Стандартная структура COCO дополнена полем `prev_imgs` в объекте `images`. Оно представляет собой массив строк с именами файлов предыдущих кадров в хронологическом порядке (от самого старого к непосредственно предшествующему).
```json
{
  "id": 1,
  "file_name": "frame_0010.png",
  "width": 1920,
  "height": 1080,
  "prev_imgs": ["frame_0005.png", "frame_0006.png", "frame_0007.png", "frame_0008.png", "frame_0009.png"]
}
```
